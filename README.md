# Teralow
Teralow is an open-source, Linux-first remote desktop platform intended to provide the ease of use of Parsec while offering first-class Linux hosting, native clients, browser access and a strong security model.

## Super Early development
Teralow is in super early development so don't go expecting greatness! I intend to have this as a fully functioning Parsec alternative for Linux.

## Goals/Achievements
Parsec has a bunch of great features included as part of their WARP tier. I plan to bring these to Teralow too, ideally free of charge. These include:

- Camera Passthrough
- Wacom/Drawing Tablet Passthrough
- Multi-monitor support
- 4:4:4 Colour Mode

Outside of their WARP tier, they bring low latency, remote desktop streaming. They have relative mouse and keyboard controls to allow for an 'immersive' experience - but only for Windows and MacOS. I intend for Teralow to be the same for all operating systems.
